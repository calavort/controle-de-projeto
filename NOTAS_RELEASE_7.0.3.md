# Controle de Projeto 7.0.3

- Adiciona sincronização automática sempre que o programa é iniciado.
- Permite definir a instalação como `HOME`, que recebe o registro, ou `EXTERNO`, que envia o registro.
- Mantém um único botão **Atualizar** para executar manualmente a ação correspondente ao ambiente definido.
- Simplifica a configuração removendo o nome redundante da máquina e textos técnicos desnecessários.
- Preserva os projetos, estatísticas, backups e a credencial local durante atualizações do programa.
